# Правила D&D 2024 (5.5e)

Здесь лежит официальный **System Reference Document 5.2.1** — открытая
(CC-BY-4.0) часть правил D&D 2024, на которую опирается проект, и русская
шпаргалка для стола.

## Файлы

- `SRD_CC_v5.2.1.pdf` — официальный SRD 5.2.1 на английском, 364 страницы,
  5,75 МиБ. Источник:
  <https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf>
  (страница загрузки: <https://www.dndbeyond.com/srd>).
  SHA-256: `8974902d109d6e63672d7c490bde9ccf052410503d9cfa768237154fbc5e3d87`.
- `cheatsheet-ru.md` — сжатая русская шпаргалка по базовым правилам,
  движения, бою, укрытиям, видимости, отдыху и состояниям. Это пересказ для
  стола и разработки, а не замена SRD.

## Что важно понимать

- SRD — не полные Player's Handbook и Dungeon Master's Guide: в нём только
  часть классов, заклинаний, монстров и предметов, открытая для совместимого
  контента. Полные книги платные и в репозиторий не кладутся.
- В спорных местах источник правды — SRD и официальные книги 2024, а не эта
  шпаргалка.
- Термины и названия классов в шпаргалке русские, в SRD — английские; при
  сверке ориентируйтесь на механику, а не на перевод названия.
